A quick reference

Three standard streams. A handful of operators.

0 · stdin Standard input1 · stdout Standard output2 · stderr Standard error
cmd | next
Connect stdout to the next command’s stdin.
< file
Read stdin from a file.
> file / >> file
Write stdout to a file / append to a file.
2> errors.log
Write stderr to a separate file.
2>&1
Copy stdout’s current destination to stderr.
&> file / &>> file
Write / append both output streams to a file.
cmd |& next
Pipe both output streams, applying the stderr copy after explicit redirects.
2>&-
Close a descriptor.

This is a static map of a simple Bash-style pipeline. It does not run commands, inspect files, or expand variables. Shell scripts, substitutions, and here-documents are outside its scope.
